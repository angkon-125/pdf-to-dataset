# Original demo assets

`demo.pdf` is a small synthetic two-page test PDF. It is not a third-party book.

Run:

```bash
python -m angkon_factory.cli examples/demo.pdf --output demo_v2_dataset.zip
```

Generated dataset ZIP files are intentionally ignored by Git. The old `demo_candidates.zip` and `demo_output.zip` from v0.1 are legacy illustrative fixtures, not output from a certified model, and are not needed for v0.2.
