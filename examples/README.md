# Example files

- `demo.pdf`: a short, original, two-page sample document to test extraction and classification.
- `demo_output.zip`: extraction-only output from `python -m angkon_factory.cli examples/demo.pdf --output examples/demo_output.zip`.
- `demo_candidates.zip`: **synthetic fixture** output with two hand-specified Q&A candidates from the sample document. It demonstrates the candidate schema and review queue; it was **not** generated by a real LLM and **neither example is automatically approved**.

For a real LLM-generated dataset, configure an Ollama or OpenAI-compatible model in the UI or CLI. Use sources you are authorized to process and train on.
